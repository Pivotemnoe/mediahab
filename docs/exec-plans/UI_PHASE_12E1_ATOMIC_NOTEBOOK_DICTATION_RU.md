# UI Phase 12E.1 — безопасная диктовка в блокнот

## Статус

Реализовано и проверено локально 02.08.2026. Production не изменён.

## Цель

Сделать главное голосовое действие в блокноте понятным и безопасным:

`нажал «Надиктовать заметку» -> записал -> закончил -> получил расшифровку через настроенный STT -> сохранилась ровно одна заметка`.

Текст сохраняется отдельной кнопкой `Сохранить идею`.

## Объём

- Переименовать быструю голосовую кнопку в `Надиктовать заметку`.
- Показать отдельные состояния: `Закончить запись` и `Расшифровываю…`.
- Добавить одну защищённую операцию API: она сначала расшифровывает загруженный голос и создаёт заметку только после успешной расшифровки.
- Если перед записью человек уже набрал текст, сохранить его перед расшифровкой в той же заметке.
- Не менять существующее дополнение голосом уже сохранённой заметки.
- В существующих таблицах сохранить принятую расшифровку, одно событие расхода и семидневный срок хранения исходного аудио.
- Проверить блокнот в дизайне Deep Forest на ширинах 390 и 1440 px.

## Вне объёма

- Установка Faster Whisper, новый провайдер STT, фоновые задания расшифровки, миграция базы, автопубликация и production-деплой.
- Изменение существующих схем заметок, медиа, хранения или учёта расхода.

## Договор API

- `POST /api/v1/notebook/transcribe-new`
- Запрос: `workspace_id`, `media_id`, необязательные `body` и `kind`, `provider_key`, а также `mock_transcript` только для тестового провайдера.
- Ответ: единственная созданная `NoteOut`.
- Если медиа не прошло проверку или расшифровка завершилась ошибкой, `NotebookNote`, `NotebookTranscription` и событие расхода не создаются.
- Проверка рабочего пространства и роли остаётся обязательной.

## Предположения

- Браузер сначала загружает и завершает голосовой `MediaAsset`, затем вызывает новую операцию.
- В production этого этапа остаётся OpenAI через уже настроенный маршрут; конфигурация NL-прокси не меняется.
- После неудачной расшифровки загруженный медиафайл может остаться для существующего механизма хранения и очистки, но пустая заметка появиться не должна.

## Миграции

Миграция не нужна. Используются существующие `notebook_notes`, `notebook_transcriptions`, `media_assets` и `usage_events`.

## Проверка

- Успешный mock STT создаёт ровно одну заметку, одну принятую расшифровку, одно событие расхода и срок хранения аудио.
- Ошибка провайдера не создаёт заметку, расшифровку и событие расхода.
- Медиа другого рабочего пространства отклоняется без создания заметки.
- Фронтенд обрабатывает отсутствие API микрофона, пустую запись, блокирует повторное действие во время обработки и показывает утверждённые русские названия.
- `make openapi`, `make lint`, `make typecheck`, целевые API-тесты, `make test`, production-сборка web, визуальные smoke-проверки и `git diff --check`.
- Проверка во встроенном браузере на 390 и 1440 px, включая консоль и горизонтальное переполнение.

## Риски

- Расшифровка OpenAI выполняется несколько секунд. На это время показывается состояние обработки и блокируется повторная отправка.
- Браузер может остановить запись без аудиоданных. Пустой файл не загружается.
- Статический маршрут может пересечься с `/notebook/{note_id}`. Он объявляется раньше динамических маршрутов и проверяется тестом.

## Откат

Откатить этот план и перевод, новую операцию API, связанные тесты и OpenAPI, а также состояния быстрой голосовой кнопки. Откат данных не нужен.

## Граница production

Этот план не разрешает изменение production. После локальной проверки владельцу показываются точный состав application-only деплоя, резервная копия, проверки здоровья и цель отката; затем требуется отдельное подтверждение.

## Итоги реализации

- Статический атомарный endpoint добавлен перед динамическими маршрутами заметок; миграция не понадобилась.
- Быстрая форма показывает `Надиктовать заметку`, `Закончить запись` и `Расшифровываю…` и блокирует повторные действия во время обработки.
- Успешный mock STT создаёт одну заметку, одну принятую расшифровку, одно событие расхода и семидневный срок хранения аудио. Ошибка провайдера и медиа другого workspace не создают заметку.
- Прошли OpenAPI, lint, typecheck, целевые и полные тесты, E2E-проверка контракта, production-сборка web, локальные миграции и seeds, проверка реального локального API во встроенном браузере на 390 и 1440 px, консоль, переполнение и `git diff --check`.
- Во время браузерного аудита не включались реальный микрофон и внешний ответ OpenAI. Существующий набор тестов NL-прокси OpenAI прошёл; короткая диктовка владельца остаётся приёмочным smoke после отдельно подтверждённого production-деплоя.

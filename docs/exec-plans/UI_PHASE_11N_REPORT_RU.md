## Ограничения

- Это срез только реального входа `/app/content/new`; сам экран созданного материала `/app/content/[contentId]` и advanced-карточки не перерабатывались в этом срезе.
- Dropdown выбора проекта/шаблона пока визуальный: он показывает текущие данные, но не открывает полноценный selector-modal. Это следующий небольшой срез.
- `Обзор места` остаётся UX-ярлыком поверх текущей рубрики до отдельного решения по persisted template name.

# Phase 12B.3: ручной пакет записи сообщества VK

Статус: реализовано и проверено локально
Дата: 1 августа 2026 года
Область: существующий композер, snapshot платформенной версии и ручной экспорт; без автоматического VK-коннектора, нового экрана, деплоя или production

## Цель

Показывать результат VK как `Запись сообщества` и готовить один устойчивый ручной пакет: финальный текст плюс текущие фото/видео в сохранённом порядке.

## Данные и API

- Сохранять в `PlatformVariant.payload.vk_export_package` пользовательский тип результата, ручной режим, количество, порядок и тип вложений, а также id обложки.
- Создавать новую VK-ревизию при изменении порядка медиа, даже если мастер-текст не менялся.
- Сохранять пакет после ручной правки и ИИ-доработки.
- Включать metadata медиа в существующий пакет коннектора `manual_export`.
- Миграция не нужна: payload версии и коннектора уже JSON.

## Интерфейс

- Заменить пользовательскую подпись VK `ручной экспорт` на `Запись сообщества`.
- В результате VK показывать `текст + N вложений`, порядок вложений и ручной режим публикации.
- Сохранить существующие кнопки копирования, редактирования и доработки.

## Граница официального API

- Записать датированный read-only spike по актуальным официальным источникам VK.
- Не придумывать числовой предел текста стены и не реализовывать автопубликацию на этом этапе.
- Будущий коннектор потребует авторизацию сообщества, загрузку медиа, идемпотентность, обработку ошибок и отдельное подтверждение владельца.

## Проверки и откат

- Проверить пустой и смешанный медиапакет, стабильный порядок, сохранение после правки и новую ревизию при смене медиа.
- Выполнить OpenAPI при изменении контракта, lint, typecheck, полный test, build и smoke 390/1440 px.
- Для отката удалить VK snapshot и пользовательские подписи; откат миграции не требуется.

## Результат

- В существующем композере VK подписан как `Запись сообщества`.
- Каждая VK-версия сохраняет `vk_export_package`: намерение финального текста, порядок и тип фото/видео, количество и id обложки.
- Изменение медиа создаёт новую VK-ревизию; ручные правки и ИИ-доработки сохраняют пакет.
- Существующий manual-export коннектор возвращает финальный текст и те же metadata вложений, сохраняя статус `manual_required`.
- Датированный официальный API spike сохранён рядом с планом. Автоматическая публикация VK осталась вне этапа.

Проверено 1 августа 2026 года: OpenAPI, lint, 78 API-тестов и 5 общих тестов, production build Next.js и responsive smoke 390/1440 px без горизонтального переполнения. Миграция не понадобилась. Production не изменялся.

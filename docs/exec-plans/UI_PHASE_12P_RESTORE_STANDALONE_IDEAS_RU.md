# UI Phase 12P — Возвращение отдельного раздела «Идеи»

## Статус

Раздел выпущен на рабочий сайт 15 августа 2026 года обновлением только Web-приложения. Локальные проверки, CI, резервная копия, переключение и послерелизная проверка пройдены.

## Цель

Вернуть в приложение уже выпущенный отдельный раздел «Идеи», не откатывая последующие улучшения текстов, записи, обучения, доступов и безопасности.

Возвращается сценарий Phase 12J:

`написать или наговорить одну тему -> получить ровно пять разных направлений -> выбрать одно -> открыть пустую запись автора`.

## Подтверждённые факты и решение

- Коммиты `ac50546`, `ce1f351` и `31e2cdd` добавили, усилили и зафиксировали рабочий production-релиз отдельного генератора.
- Коммит `8caebf0` сохранил страницу, компонент, передачу выбранной идеи, API, проверки и историю в базе, но при упрощении закрытого пилота убрал `/app/ideas` из компьютерного и мобильного меню.
- Текущий production API сообщает, что отдельный генератор включён, а исходный кабинет владельца находится в списке доступа.
- Отдельный запуск по-прежнему не связан с проектом, рубрикой или публикацией, не загружает примеры и передаёт модели только тему пользователя.
- Проверка по-прежнему требует ровно пять направлений и отклоняет одинаковые или слишком похожие варианты.

Phase 12P отменяет только решение Phase 12N скрыть вход в «Идеи». Все остальные решения Phase 12N и Phase 12O сохраняются.

## Объём работы

- Вернуть «Идеи» в основное меню приложения на компьютере и телефоне.
- Сохранить нынешние понятные названия (`Наговорить`, `Тексты`, `Блокнот`, `Мой стиль`) и добавить «Идеи» пятым мобильным разделом.
- Оставить «Идеи» отдельной сущностью `/app/ideas`; не встраивать старый проектный генератор в экран диктовки.
- Обновить проверки интерфейса, чтобы наличие раздела снова было обязательным условием релиза.
- Добавить отдельную проверку Phase 12P: страница остаётся самостоятельной, а защита пяти вариантов от повторов присутствует.
- Не менять API, структуру базы, миграции, сохранённые публикации, список разрешённых кабинетов, отправку публикаций и сценарий первого обучения.

8. После свежей резервной копии заменить только Web-контейнер и проверить готовность сайта и раздел «Идеи» после входа.

## Риски и меры

- Пять пунктов занимают больше места в мобильном меню. Проверить нынешние названия при ширине 390 пикселей и сохранить равные адаптивные колонки.
- Кабинет вне списка доступа может увидеть существующее понятное сообщение о недоступности. Не расширять production-список в рамках этого возврата.
- Широкий откат может удалить последующие улучшения пилота. Возвращать только навигацию и проверки поверх текущей версии.

## Откат

- Не менять API, worker, PostgreSQL, Redis, тома, миграции, флаги и историю запусков генератора.

# UI Phase 12A.3 - Качество редакции, настоящие правки и контроль стоимости

## Статус

Реализовано, опубликовано и проверено на production 2026-07-30.

## Что подтверждено на production

Релиз `20260730-1845-phase12a3-photo` опубликован на `temichev-posthub.ru` со следующими проверками:

- пересозданы только контейнеры `api`, `worker` и `web`; PostgreSQL, Redis, Docker volumes, Caddy и соседние сервисы продолжили работать;
- база осталась на ревизии Alembic `202606200008 (head)`, миграция не потребовалась;
- редакторская production-модель — `gpt-5.6-terra`, вспомогательные задачи остались на `gpt-4.1-mini`, проверка доступности редакторской модели через настроенный NL-relay получила HTTP 200;
- в авторизованном боевом редакторе подтверждены необязательная рубрика, Telegram/MAX/VK/Instagram, раздел до десяти фото, пояснение про первые три фото для ИИ и редактируемые предложения четырёх оценок;
- production health готов, публичные главная, регистрация и вход возвращают HTTP 200;
- резервная копия для отката хранится в `/var/www/media-hub-releases/previous-20260730-1845-phase12a3-photo`.

Последний реальный материал проекта `Что поесть? Армавир`, рубрика `Фаст-обзор`, показал, что первая сборка уже может дать полезный структурированный черновик, но контур доработки пока небезопасен:

- production-модель текста: `gpt-4.1-mini`;
- модель расшифровки: `gpt-4o-mini-transcribe`;
- модель эмбеддингов: `text-embedding-3-small`;
- принятая запись использовала 2 928 входных аудиотокенов и 874 выходных токена;
- первая цепочка ИИ получила одобренный пример рубрики и запасные общие примеры проекта;
- первая мастер-сборка завершилась и дала структурированный текст на 2 416 знаков;
- последующее нажатие `Пересобрать` упёрлось в тайм-аут, после чего backend молча сохранил текст на 3 009 знаков, собранный почти напрямую из расшифровки;
- этот запасной текст заменил полезный результат в простом редакторе без понятного сообщения об ошибке провайдера;
- `Короче`, `Живее` и `Без эмодзи` сейчас выполняют локальные замены строк, а не редактуру ИИ;
- поле свободной команды показывается, но команда никуда не отправляется;
- локальная команда `Живее` может портить пунктуацию, например превращать точку в сокращении `ул.` в `!`;
- простой редактор предлагает Reels, хотя владелец хочет оставить в нормальном потоке Telegram, MAX, VK и Instagram.

## Цель

Сделать нормальный путь честным и полезным:

`надиктовать -> собрать сильный мастер -> получить версии площадок -> доработать одну версию без потери последнего хорошего результата -> увидеть стоимость и предупреждения`

## Продуктовые решения

1. Оставить `gpt-4.1-mini` для ограниченных задач извлечения фактов, крючка и предложений оценок.
2. Использовать отдельную более сильную редакторскую модель для мастер-сборки и доработки вариантов. Первый кандидат — `gpt-5.6-terra` с низким уровнем рассуждения: это актуальный сбалансированный уровень OpenAI, а не самый дорогой frontier-вариант.
3. Не показывать неудачу провайдера как успешную пересборку.
4. Неудачная пересборка сохраняет последний хороший мастер и вариант площадки.
5. Быстрые команды становятся настоящими правками ИИ и создают неизменяемые ревизии варианта.
6. У свободной команды появляется явная кнопка `Применить`; по умолчанию команда относится только к открытой площадке.
7. Reels убирается из обычного редактора. Telegram, MAX, VK и Instagram остаются.
8. Instagram остаётся отдельно адаптируемым результатом с ручной проверкой и лимитом 2 200 знаков. Это не обещание живой публикации через Meta.
9. К материалу можно прикрепить до десяти фотографий публикации. Первые три поддерживаемых изображения один раз передаются в экономном режиме при извлечении фактов, чтобы чек, меню и упаковка помогали редактору без повторной оплаты изображений на каждом шаге ИИ.
10. Цены и надписи, прочитанные с фотографии, остаются неподтверждёнными подсказками до проверки пользователем.
11. Все четыре оценки всегда предлагаются по всей диктовке и описанию. Прямые оценки пользователя имеют приоритет; оценки ИИ остаются редактируемыми предложениями с объяснением.

## Реализация

### Backend

- Добавить отдельную настройку `OPENAI_EDITOR_MODEL`, сохранив `OPENAI_TEXT_MODEL` для вспомогательных задач.
- Выбирать редакторскую модель для `assemble_master` и доработки вариантов.
- Записывать оценочную стоимость в микро-USD на основе модели и фактических токенов.
- Добавить контракт доработки варианта площадки через ИИ, в который входят:
  - текущий текст варианта;
  - исходная расшифровка;
  - правила проекта и рубрики;
  - небольшой набор релевантных одобренных примеров;
  - профиль и лимит площадки;
  - одна быстрая или свободная команда;
  - структурированный JSON-ответ.
- Успешную правку сохранять через существующий сервис неизменяемых ревизий вариантов.
- При тайм-ауте или неверном структурированном ответе возвращать ошибку API и не создавать заменяющий вариант.
- Сохранить внутренний запасной контур для первой сборки, но показывать его предупреждение и не разрешать ему заменять последний хороший результат при пересборке.
- Передавать до трёх JPEG/PNG/WebP-вложений в Responses API при извлечении фактов с детализацией `low`, затем использовать структурированное извлечение в мастер-сборке.
- Передавать в мастер-сборку завершённые результаты извлечения фактов, крючка и оценок вместо их потери.

### Frontend

- Заменить локальные строковые преобразования настоящим endpoint доработки.
- Добавить быстрые команды:
  - `Короче`;
  - `Живее`;
  - `Больше юмора`;
  - `Без эмодзи`;
  - `Пересобрать`.
- Добавить кнопку `Применить команду` для свободной инструкции.
- Во время доработки сохранять текущий текст на экране и показывать загрузку.
- Показывать предупреждения провайдера и запасной сборки в карточке результата.
- Убрать Reels из обычного выбора площадок.
- Оставить Instagram доступным и независимым.
- Рядом с расшифровкой добавить короткую подсказку для диктовки: заведение и адрес, блюдо, цена и вес, атмосфера, упаковка, вкус и повторный заказ; объяснить, что четыре оценки предложит ИИ и пользователь сможет их исправить.
- Добавить отдельный раздел фотографий с лимитом десять штук на публикацию, проверкой 8 МБ на файл, подсказкой по форматам и явным пояснением, что первые три фото участвуют в ИИ-сборке.

### Стоимость

- Рассчитывать и сохранять стоимость генерации, когда OpenAI вернул использование токенов.
- Сохранять использование токенов расшифровки из ответа OpenAI.
- Добавить тесты известных тарифов моделей и поведения для неизвестной модели.
- Не выдавать оценку приложения за точный счёт OpenAI: счёт провайдера остаётся главным, особенно если запрос завершился тайм-аутом и usage не вернулся.

## Приёмочные сценарии

1. Первая мастер-сборка использует редакторскую модель и возвращает структурированный пост.
2. `Живее` создаёт новую ревизию через ИИ и не портит сокращения.
3. `Больше юмора` добавляет связанный с ситуацией юмор и не придумывает факты.
4. Свободная команда действительно отправляется и по умолчанию меняет только открытую площадку.
5. Режим `Применить ко всем` независимо дорабатывает каждую выбранную площадку.
6. Тайм-аут провайдера оставляет последний хороший вариант на экране и показывает понятную русскую ошибку.
7. Reels отсутствует в обычном редакторе.
8. Telegram, MAX, VK и Instagram доступны для выбора.
9. Instagram адаптируется отдельно и не превышает 2 200 знаков.
10. В истории генераций сохраняются модель, токены, задержка, статус и оценочная стоимость для известных тарифов.
11. Раздел фото принимает до десяти JPEG/PNG/WebP и понятно показывает ход загрузки.
12. Не больше трёх прикреплённых фото передаются в один мультимодальный запрос извлечения фактов с детализацией `low`; байты изображений не сохраняются в метаданных запуска.
13. Мастер-сборка получает завершённые результаты вспомогательных задач, а все четыре оценки имеют значение пользователя или явно помеченное предложение ИИ.

## Риски

- Сильная модель дороже; вспомогательные задачи не должны автоматически перейти на неё.
- Повтор больших правил проекта и рубрики и всех примеров увеличивает задержку и стоимость. Подбор должен оставаться небольшим и убирать дубли без потери приоритета рубрики.
- Запрос с тайм-аутом может быть оплачен, даже если приложение не получило usage.
- Цена анализа изображения зависит от модели, разрешения, детализации и кадрирования. Экономику чеков нужно измерить на реальных примерах, а не обещать фиксированную цену фотографии.
- Изображения передаются ограниченными base64 data URL через существующий NL-relay; в аудите сохраняются только количество и режим детализации, но не байты фото.

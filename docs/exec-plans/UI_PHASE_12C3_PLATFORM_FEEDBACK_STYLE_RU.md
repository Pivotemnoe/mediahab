# UI Phase 12C.3 - Реакции по площадкам и внутренний стиль

## Статус

Реализовано и принято локально 2026-08-01. Production не меняется без отдельного подтверждения владельца.

## Цель

Дать отдельную обратимую оценку каждой версии Telegram, MAX, VK и Instagram. Только явно отмеченный как отличный финальный текст после ручной правки может стать внутренним примером стиля проекта и площадки. OpenAI и внешняя модель не обучаются, публикация автоматически не запускается.

## Решения

1. Реакция относится к одной неизменяемой `PlatformVariant`, workspace, пользователю и площадке.
2. Варианты: `excellent`, `good`, `needs_work`, `not_my_style`; можно добавить короткий комментарий.
3. Реакцию можно заменить или снять. После повторного открытия показывается последняя активная оценка.
4. В стиль попадает только `excellent` с явным `learn_style=true`.
5. Учиться можно только на версии, созданной ручной правкой пользователя. Нетронутый ответ ИИ, сырой блокнот, расшифровка или отклонённый вариант автоматически не используются.
6. Сохраняется точный финальный текст конкретной ревизии в границе workspace → проект → рубрика → площадка. Новая правка создаёт новую ревизию и требует новой реакции.
7. Пример использует существующий контур approved examples с `source_type=variant_feedback` и меткой площадки. Общая мастер-сборка исключает такие примеры; доработка конкретной площадки может брать только совпадающую площадку.
8. Замена/снятие отличной реакции отключает только пример, созданный этой реакцией. Ручные примеры не затрагиваются.
9. Реакция не равна одобрению публикации: ручное подтверждение отправки остаётся отдельным.

## Данные, API и интерфейс

- Новая таблица `platform_variant_feedback`: workspace, проект, площадка, вариант, автор, реакция, комментарий, ссылка на принадлежащий реакции пример, даты и версия.
- GET/PUT/DELETE для реакции конкретной версии.
- Компактные кнопки под каждой готовой версией в простом редакторе и истории сохранённого материала.
- Подсказка прямо говорит: «запомнить стиль» создаёт внутренний пример, а не обучает OpenAI.

## Проверка и откат

- Изоляция workspace, независимость площадок, замена/снятие реакции.
- Запрет обучения на нетронутом ИИ-тексте; точное сохранение ручного финального текста.
- Отключение только feedback-примера и фильтрация по площадке при retrieval.
- Контролы видны на 390 и 1440 px без горизонтального переполнения.
- Откат удаляет только feedback-таблицу, API, кнопки, отметку ручной правки и ветку retrieval; варианты и ручные примеры остаются.

## Результат проверки

- API-проверка подтверждает независимые реакции Telegram/MAX, замену/снятие, точное запоминание финального ручного текста и запрет для нетронутого ответа ИИ.
- Доработка площадки получает только свой пример; master и другие площадки его исключают.
- Feedback-пример утверждается без вызова embedding-провайдера: реакция не обучает OpenAI, не тратит токены OpenAI и работает при недоступности провайдера.
- В реальном локальном API-сценарии сохранены `excellent + запомнить стиль` для Telegram и отдельное `needs_work` для MAX; обе реакции сохранились в «Истории».
- На 390 и 1440 px кнопки видны, горизонтального переполнения нет.
- Lint, typecheck, OpenAPI, focused-тест и общий прогон прошли; совместный прогон после Phase 12C.4 показывает 97 успешных API-тестов.

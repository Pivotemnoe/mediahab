# UI Phase 12J — Самостоятельный генератор идей

## Статус

Выполняется.

## Цель

Выпустить генератор идей именно как отдельную простую часть приложения:

`сказать или написать тему -> получить ровно пять направлений -> выбрать одно -> надиктовать авторское содержание -> позже отдать ИИ на редактуру`.

Генератор не привязан к проекту или рубрике и не является общим чатом. Он не создаёт пост, не отвечает на вопрос пользователя и не пишет готовый к публикации текст.

## Продуктовые решения

- Добавить самостоятельный авторизованный маршрут `/app/ideas` с названием `Идеи` в desktop- и mobile-навигацию.
- В мобильном меню заменить вкладку `Мой стиль` на `Идеи`; `Мой стиль` остаётся в desktop-меню и на dashboard, а в мобильной панели остаются пять читаемых действий: `Главная`, `Создать`, `Идеи`, `Черновики`, `Блокнот`.
- Для генерации нужна одна непустая тема. Её можно написать или получить из короткой записи микрофона.
- Backend возвращает ровно пять компактных объектов: `id`, `title`, `direction` и `speaking_prompt`.
- `direction` описывает, о чём автор может рассказать. `speaking_prompt` — один вопрос, помогающий начать диктовку. Это не черновик, не фактический ответ, не рекомендация и не придуманная история от первого лица.
- Endpoint работает как одноразовый структурированный генератор. В нём нет истории диалога, свободного ответа ассистента, продолжения чата, выбора модели и произвольных инструментов.
- Генерация и выбор идеи не создают `ContentItem`. Кнопка `Надиктовать по этой идее` сохраняет короткоживущую локальную planning-ссылку и открывает существующий редактор с пустой расшифровкой.
- Проект и рубрика выбираются только в редакторе. Когда пользователь начинает настоящую работу и редактор создаёт материал, выбранное направление сохраняется отдельно как `ai_suggested`; оно не становится авторским исходником или зафиксированным фактом.
- Прежний генератор по проекту/рубрике остаётся выключенным и убирается с основной поверхности редактора. Его endpoint и исторические runs сохраняются для совместимости, аудита и отката.
- Самостоятельный генератор использует внутреннюю настроенную модель идей. Название провайдера/модели, prompts, цены токенов и технические лимиты не показываются в основном интерфейсе.

## Объём backend

- Добавить workspace-scoped endpoints capability, генерации и расшифровки темы.
- Сделать `GenerationRun.project_id` nullable и обновить тип ответа API, чтобы у самостоятельного run не было ложной связи с проектом.
- Добавить отдельный task type и feature flag самостоятельных направлений. Старый флаг проектного генератора остаётся выключенным.
- Сохранить проверку подписки, месячной AI-квоты, редакторской роли, доступа к workspace, дневного лимита, долговечные `GenerationRun`/`GenerationStep` и одно идемпотентное usage event на run.
- Учитывать самостоятельные и старые проектные подборки в общем дневном лимите идей.
- Генерировать только из темы пользователя. Не подбирать примеры проекта, рубрики, недавние заголовки и материалы.
- Использовать строгую схему пяти элементов и детерминированно проверять точное количество, длины, уникальность, однострочный формат, отсутствие URL/цитат/инструкций, неподанных имён, чисел, дат, цен и утверждений от первого лица.
- При ошибке провайдера/схемы/валидации разрешить один ограниченный полный повтор внутри того же run и квоты. Вторая ошибка возвращает стабильный код и ни одной идеи.
- Расшифровывать короткое загруженное голосовое медиа workspace без создания заметки в блокноте. Учитывать STT usage и применять существующий короткий срок хранения исходного аудио.
- Считать переданный браузером `duration_ms` недоверенной подсказкой о записи. До вызова провайдера резервировать полный лимит записи темы — 120 секунд — и никогда не вычислять списание из браузерных метаданных. В будущем безопасный пересчёт возможен только по длительности, подтверждённой серверным анализатором медиа.
- Повторять неудачный самостоятельный run без требования проекта. Поведение retry старого проектного run не меняется.

## Объём frontend

- Добавить mobile-first страницу с одним основным полем темы, понятным состоянием микрофона, одной кнопкой `Предложить 5 идей`, остатком дневных подборок и пятью компактными карточками.
- Сохранить систему Deep Forest, текущие карточки/кнопки/badges, радиусы и типографику, а также явный прогресс записи, загрузки и расшифровки.
- Не разрешать генерацию при пустой теме и во время активного запроса. Отменять устаревшие запросы при уходе со страницы.
- Сохранять введённую тему при ошибке голоса и заменять её только после успешной расшифровки.
- `Надиктовать по этой идее` открывает `/app/content/new?idea=<handoff-token>`, показывает выбранное направление как planning reference, переводит фокус на авторский ввод и оставляет текст автора пустым.
- Если в workspace ещё нет проекта, редактор сохраняет точный handoff, показывает выбранное направление и предлагает одно главное действие `Создать проект и продолжить`. После создания проекта пользователь возвращается на `/app/content/new?project=<project-id>&idea=<handoff-token>` без создания материала и без замены стабильного client content id в handoff.
- Просроченные и повреждённые локальные handoff игнорируются. Handoff удаляется только после сохранения planning reference редактором или явного отказа пользователя.
- Добавить `Идеи` в быстрые действия и публичное описание функции, не обещая обучение на стиле проекта для этого самостоятельного сценария.

## API-контракт

```text
GET  /workspaces/{workspace_id}/ideas/capability
POST /workspaces/{workspace_id}/ideas/generate
POST /workspaces/{workspace_id}/ideas/transcribe-topic
```

Запрос генерации:

```json
{ "topic": "Как владельцу маленькой кофейни рассказывать о команде" }
```

Ответ остаётся существующим долговечным `GenerationRunOut`, где `project_id: null`, а внутри:

```json
{
  "ideas": [
    {
      "id": "idea-1",
      "title": "Один незаметный ритуал команды",
      "direction": "Рассказать о небольшом рабочем ритуале и о том, почему он важен лично вам.",
      "speaking_prompt": "Какой реальный момент вы наблюдаете почти каждый день?"
    }
  ]
}
```

## Миграция и откат

- Миграция `202606200013` меняет только `generation_runs.project_id` на nullable.
- Downgrade останавливается, если существуют самостоятельные runs с `project_id IS NULL`; история аудита автоматически не удаляется.
- Для отката выключается флаг самостоятельного генератора, убираются пункт меню/страница и возвращаются прежние образы приложения. PostgreSQL, Redis, медиа, публикации, авторские исходники и исторические runs сохраняются.

## Проверки приёмки

- `/app/ideas` виден на desktop и при ширине 390 px, не имеет горизонтального overflow и не требует проект.
- Написанная тема даёт ровно пять разных направлений. Не создаётся ни material, ни block, ни note, ни publication.
- Для голоса видны состояния подключения, записи, загрузки, расшифровки, успеха и ошибки; успешная расшифровка заполняет только поле темы.
- Посторонний вопрос `Какая сегодня погода?` превращается в направления для постов о личном опыте, связанном с погодой, и никогда не получает ответ о погоде.
- Чувствительные темы дают редакционные направления/вопросы, а не медицинские, юридические, финансовые, психологические, ветеринарные или фитнес-рекомендации.
- В результате нет неподанных имён, дат, цен, цитат, URL, событий от первого лица и готовых публикационных абзацев.
- Выбор направления открывает редактор, показывает идею и оставляет расшифровку пустой. Сборка заблокирована до авторского исходника.
- В workspace без проектов выбранная идея переживает создание первого проекта и возвращается в редактор к авторскому вводу; ни переход, ни создание проекта не создают материал.
- Один выбор проекта ничего не создаёт. Начало диктовки или сохранение авторского текста создаёт ровно один материал и отдельно сохраняет идею в незаблокированном `ai_suggested`-блоке.
- Refresh/resume никогда не принимает выбранное направление за расшифровку автора.
- Доступ к workspace, роль, подписка, месячная квота, дневной лимит, CSRF и идемпотентное резервирование usage проверяются до вызова провайдера.
- Значение `duration_ms=1` у непроверенной или длинной голосовой записи никогда не приводит к резерву или списанию одной секунды: endpoint резервирует консервативный максимум 120 секунд.
- Старый проектный генератор выключен на production, а новый самостоятельный флаг включён.

## Риски

- Даже направления могут быть общими. Карточки остаются короткими и зовут к конкретному наблюдению автора, а обучение стилю происходит позже в редакторском сценарии, не возвращая сюда привязку к проекту.
- Браузер может отказать в микрофоне или запись может завершиться ошибкой. Введённый текст сохраняется, каждое состояние видно, ручной ввод всегда доступен.
- Nullable `project_id` расширяет зрелый audit-контракт. Workspace остаётся обязательным, а retry явно разделяется по task type.
- Через standalone prompt пользователь может попытаться превратить endpoint в ChatGPT. Жёсткая схема ответа, одноразовый API, system instruction, validator и отсутствие истории диалога удерживают границу.

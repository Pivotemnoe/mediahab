# Phase 12B.2a: счётчик расхода ИИ

Статус: реализовано и проверено локально
Дата: 1 августа 2026 года
Область: существующий Voice First композер и уже работающий учёт generation run; без нового экрана, изменения биллинга, деплоя или production

## Цель

После текстовой сборки или доработки показывать владельцу понятную оценку расхода:

- входные токены;
- выходные токены;
- общий расход токенов;
- примерную стоимость провайдера в долларах.

Это операционная оценка экономики продукта, а не счёт и не сумма, которую следует автоматически брать с клиента.

## Данные и API

- Использовать существующие `GenerationRun.input_tokens`, `output_tokens`, `input_characters`, `output_characters` и `cost_estimate_micro_usd`.
- Добавить токены в существующий ответ доработки платформенной версии, чтобы композер мог сложить все вызовы одной сборки.
- Сначала использовать usage провайдера. Если токенов нет, но есть число символов, приблизительно считать `ceil(символы / 4)` и явно помечать оценку.
- Не добавлять миграцию и не менять usage подписки или тарифные цены.

## Интерфейс

- Добавить компактный блок `Расход ИИ на последнюю операцию` под существующими результатами площадок.
- На мобильном показать вход, выход, итог и USD без сложной таблицы.
- Явно пояснить, что расшифровка и будущий анализ изображений не входят в число текстовых токенов.

## Проверки и откат

- Проверить точный usage провайдера, приблизительный расчёт по символам, суммирование и поля ответа refinement.
- Выполнить lint, typecheck, API-тесты, web build и responsive smoke.
- Для отката удалить поля ответа и UI-блок; сохранённые generation runs не меняются.

## Результат

- Композер складывает все завершённые generation run последней полной сборки или явной доработки.
- Если провайдер вернул токены, показываются они; иначе входные/выходные символы пересчитываются по документированному приблизительному правилу и помечаются `примерно`.
- Блок показывает вход, выход, общий расход и оценку стоимости провайдера. Расшифровка и анализ изображений явно исключены из текстового токен-счётчика.
- Ответ API доработки теперь включает токены и символы. Миграция не потребовалась.

Проверено 1 августа 2026 года: `make openapi`, `make lint`, `make test` (78 API-тестов и 5 общих тестов), production build Next.js и responsive smoke 390/1440 px. Production не изменялся.

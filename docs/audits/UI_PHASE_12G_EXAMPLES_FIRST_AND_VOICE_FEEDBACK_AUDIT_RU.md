# Аудит UI Phase 12G — стиль по примерам и понятная диктовка

Дата: 11.08.2026

## Итог

Основной путь MediaHub сокращён до последовательности `название канала -> удачные посты -> диктовка`. Длинная анкета сохранена как дополнительный инструмент, но больше не мешает первому запуску. Блокнот показывает честные этапы записи, локального сохранения и отправки без выдуманных процентов и обещания фоновой синхронизации.

## Исправленные проблемы

- «Мой стиль» теперь ведёт к подборке удачных публикаций и показывает ориентир `N из 10`.
- На первом экране создания открыты только название и тематика; структура, аудитория, юмор, CTA и запреты находятся в «Дополнительных настройках».
- Примеры можно добавлять по одному или массово через разделитель `---`, удалять до сохранения и при необходимости относить к рубрике.
- Интерфейс предлагает использовать чужие посты только как ориентир по ритму и подаче; факты нового материала задаются новой диктовкой, а финальный текст остаётся под контролем пользователя.
- Быстрая диктовка различает подключение микрофона, активную запись, локальное сохранение, ожидание связи, отправку, расшифровку и готовность.
- Во время записи предусмотрены таймер, настоящий уровень сигнала и заметная кнопка «Остановить и сохранить».
- Для текста показывается подтверждение автосохранения на устройстве; для офлайн-очереди — состояние каждой заметки и честное требование снова открыть приложение при интернете.

## Браузерная проверка

- Проверены маршруты `/app/style`, `/app/projects/new`, `/app/projects/chto-poest-armavir/examples` и `/app/notebook`.
- Размеры: `1280 x 720` и `390 x 844`.
- Проверены раскрытие дополнительных настроек, одиночная вставка, массовая вставка, изменение счётчика с `0` до `3`, удаление до `2`, доступность основных кнопок и нижняя мобильная навигация.
- На всех проверенных маршрутах `scrollWidth` совпадает с шириной viewport; горизонтального переполнения нет.
- В консоли браузера нет `warn` и `error`.
- Реальный доступ к микрофону в автоматической проверке не выдавался. Голосовой путь требует короткой приёмки владельцем на телефоне после production-релиза.

Локальные снимки проверки находятся в `tmp/ui-phase12g-audit/` и намеренно не входят в release archive.

## Production

- Web-only релиз `20260811-092631-phase12g-examples-first` опубликован из commit `e90079b1e7a12e4ee5848e3805d71a4c3b830469`.
- Пересоздан только Web. ID API, Worker, PostgreSQL и Redis, именованные volumes и контрольные количества данных не изменились.
- Public live/ready, главная, `/features` и офлайн-блокнот отвечают `200`; production-страницы стиля, примеров и блокнота открыты во встроенном браузере без ошибок консоли и горизонтального переполнения.
- Перед переключением сохранены исходники, конфигурация, валидируемый dump PostgreSQL и rollback-образ Web.
